# Task: Align Keel Governance Docs, Config/Deploy Hygiene, and Broken Eval Scripts

## Goal & Why

`papervault` has evolved from its early July 2026 closed-beta prototype (5k space-physics papers, GitHub Issues tracking, per-PR global version bumps) into a ~30k-paper personal single-host research literature & knowledge infrastructure covering space physics, space computing, and AI4Science alongside operator textbooks/notes, served via MCP to Antigravity, Claude Code, and Codex agents.

Currently:
1. Root `AGENTS.md` is a legacy 4-section memo lacking Keel's six-section structure (`## Core need`, `## Design Philosophy`, `## Architecture & Boundaries`, `## Commands`, `## Gotchas`, `## Where to look`), still points task tracking to GitHub Issues, and mandates per-PR global version bumps (causing parallel worktree collisions and violating Keel release-time versioning).
2. `docs/PRD.md` still describes the July 2026 closed-beta/private-repo prototype (5,165 papers, space physics only, MinerU vLLM, Claude Code only) and lacks the detailed `## Design Philosophy` section required by Keel.
3. Multiple docs and deployment templates drifted out of sync (`README.md` hardcodes `0.10.15` & "closed beta"; `docs/architecture.md` & `docs/INSTALL.md` omit space computing and active runtime/systemd knobs; `deploy/papervault.service` lacks `LimitNOFILE=65536`, `MALLOC_ARENA_MAX=2`, and CPU thread caps; `ADR-0003`/`ADR-0004` and the ratified constitution spec lack status/amendment updates; `.env.example` omits active runtime env vars).
4. Search/eval scripts have real bugs: `scripts/mustfind_recall.py` crashes with `FileNotFoundError` writing to nonexistent `src/papervault/eval/results/`; `scripts/search_relevance_baseline.py` writes paper-text artifacts inside `src/` (violating the no-paper-data-in-`src/` gate) and ignores `config.USE_GATEWAY=False`; `src/papervault/eval/judge_mimo.py` and `src/papervault/eval/_ab_u1_judge.py` require legacy `KS_VIRTUAL_KEY`/`KS_GATEWAY_URL` instead of falling back cleanly to `papervault.config`.

This slice establishes the Keel documentation & governance baseline and repairs the broken eval scripts and config/deploy templates **without** bumping the global package version and **without** touching the primary checkout's `.env`, `.venv`, data, or live systemd service.
